## 1. Exact Match (EM) Evaluation

### Definition
Exact Match (EM) is an evaluation metric used to measure whether a model's predicted answer exactly matches the reference answer.

- It is commonly used for question-answering tasks, multiple-choice questions (MCQs), and mathematical answers.
- If the prediction matches the reference answer, the score is 1; otherwise, it is 0.

**Formula:**

$$
EM = \frac{1}{N}\sum_{i=1}^{N} score_i
$$

Where:
- \(N\) = Total number of questions.
- \(score_i = 1\) if the prediction exactly matches the reference.
- \(score_i = 0\) otherwise.

### Normalized Exact Match
Because exact matching is very strict, researchers sometimes use normalized text before comparing answers.

Common normalization steps include:
- Convert all letters to lowercase.
- Remove punctuation.
- Remove extra spaces.
- Remove articles such as "a", "an", and "the" (depending on the evaluation task).

**Advantages:**
- Simple and easy to understand.
- Provides a clear measure of exact correctness.
- Useful for short answers and factual question-answering tasks.

**Limitations:**
- Too strict for long sentences and natural-language answers.
- Different wording with the same meaning may receive a score of 0.
- Normalization may remove meaningful differences if applied incorrectly.

## 2. Accuracy Evaluation

### Definition
Accuracy measures the proportion of predictions that the model classifies correctly out of all predictions.

**Formula:**

$$
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
$$

Where:
- TP (True Positive): Correctly predicted positive cases.
- TN (True Negative): Correctly predicted negative cases.
- FP (False Positive): Incorrectly predicted positive cases.
- FN (False Negative): Incorrectly predicted negative cases.

**Advantages:**
- Intuitive and easy to understand.
- Provides an overall measure of classification performance.
- Useful when classes are relatively balanced.

**Limitations:**
- Can be misleading when working with imbalanced datasets.
- Does not explain what types of mistakes the model makes.
- A model can achieve high accuracy while performing poorly on a minority class.

## 3. Precision, Recall, and F1-Score

These metrics are used to evaluate classification performance, especially when the dataset is imbalanced.

### Precision
Precision tells us how many of the model's positive predictions are actually correct.

$$
Precision = \frac{TP}{TP + FP}
$$

### Recall
Recall tells us how many of the actual positive cases the model successfully identifies.

$$
Recall = \frac{TP}{TP + FN}
$$

### F1-Score
F1-Score is the harmonic mean of Precision and Recall. It balances both metrics.

$$
F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}
$$

**Advantages:**
- Provides more detailed information than accuracy.
- Useful for imbalanced datasets.
- F1-Score balances Precision and Recall.

**Limitations:**
- A single F1-Score can hide class-specific performance.
- Depends on reliable ground-truth labels.
- Does not account for different costs associated with different types of errors.

## 4. BLEU Score (Bilingual Evaluation Understudy)

### Definition
BLEU is an evaluation metric originally developed for machine translation. It measures how much the generated text overlaps with one or more reference texts using n-gram precision.

An n-gram is a sequence of N consecutive words.

For example:
- Unigram: "I"
- Bigram: "I love"
- Trigram: "I love AI"

### Evaluation Process

1. Compare: Compare the candidate text with reference text.
2. Count: Count matching n-grams.
3. Clip: Limit the number of matching n-grams so repeated words cannot receive excessive credit.
4. Calculate: Calculate modified n-gram precision.
5. Penalize: Apply a brevity penalty if the candidate is too short.

### Formula

**Brevity Penalty (BP):**

$$
BP =
\begin{cases}
1 & \text{if } c \geq r\\
e^{(1-r/c)} & \text{if } c < r
\end{cases}
$$

Where:
- \(c\) = Length of the candidate text.
- \(r\) = Effective reference length.

**BLEU Score:**

$$
BLEU = BP \times \exp\left(\sum_{n=1}^{N}w_n\ln p_n\right)
$$

Where:
- \(p_n\) = Modified n-gram precision.
- \(w_n\) = Weight assigned to each n-gram order.
- \(N\) = Maximum n-gram order (commonly 4).

When equal weights are used, \(w_n = 1/N\).

**Advantages:**
- Fast and inexpensive to calculate.
- Repeatable and widely established.
- Useful for comparing machine translation systems.

**Limitations:**
- Does not directly evaluate factual correctness.
- May penalize valid paraphrases that use different words.
- Can be unreliable for very short sentences.

## 5. ROUGE Score (Recall-Oriented Understudy for Gisting Evaluation)

### Definition
ROUGE is an evaluation metric mainly used for text summarization and other text-generation tasks.

It measures how much important information from the reference text is captured in the generated output.

### Main Types of ROUGE

1. **ROUGE-N (N-gram Overlap):**
   Measures the overlap of N consecutive tokens between the generated text and reference text.

2. **ROUGE-L (Longest Common Subsequence):**
   Measures the longest sequence of matching tokens in the same order. Unlike consecutive phrases, a subsequence can skip intervening words.

3. **ROUGE-Lsum (Summary-level LCS):**
   Uses sentence-level alignment and the union of matched reference-token positions to evaluate summaries.

4. **ROUGE-W (Weighted Longest Common Subsequence):**
   A weighted version of LCS that gives more credit to consecutive matching sequences than to scattered matches.

5. **ROUGE-S (Skip-bigram Overlap):**
   Measures matching ordered pairs of tokens, allowing gaps between the two words.

6. **ROUGE-SU (Skip-bigram plus Unigram):**
   Combines skip-bigram overlap with individual-word overlap. This provides credit when texts share words but have no matching ordered pairs.

**Advantages:**
- Useful for evaluating text summarization.
- Provides different ways to measure text overlap.
- Can evaluate how much reference information is retained.

**Limitations:**
- Limited semantic understanding.
- May penalize valid paraphrases.
- Results can depend on language-specific preprocessing and tokenization.
- High ROUGE scores do not guarantee factual correctness.

## 6. METEOR Score (Metric for Evaluation of Translation with Explicit ORdering)

### Definition
METEOR evaluates generated text by comparing it with reference text. It considers word matching, word order, and similarities between words.

### Evaluation Process

1. Compare the candidate text with the reference text.
2. Align matching words.
3. Calculate Precision and Recall.
4. Check the order of matched words.
5. Apply a fragmentation penalty.
6. Calculate the final METEOR score.

### Word Alignment

METEOR can use different matching stages:

- Exact match: Matches identical words.
- Stem match: Matches words with the same root or stem.
- Synonym match: Matches words with similar meanings using lexical resources.

### Formulas

**Precision:**

$$
P = \frac{m}{\text{Number of candidate words}}
$$

**Recall:**

$$
R = \frac{m}{\text{Number of reference words}}
$$

Where \(m\) is the number of aligned word matches.

**Weighted F-Mean:**

$$
F_{mean} = \frac{10PR}{R+9P}
$$

**Fragmentation Penalty:**

$$
Penalty = 0.5 \times \left(\frac{chunks}{m}\right)^3
$$

Where:
- chunks = Number of matched word chunks.
- \(m\) = Number of aligned word matches.

**Final METEOR Score:**

$$
METEOR = F_{mean} \times (1-Penalty)
$$

**Advantages:**
- Considers both Precision and Recall.
- Supports stemming and synonym matching.
- Takes word order into account.
- More flexible than exact n-gram matching.

**Limitations:**
- Does not prove that the generated answer is factually correct.
- Depends on language resources such as stemming and synonym dictionaries.
- May not recognize all creative paraphrases.

## 7. BERTScore

### Definition
BERTScore is an automatic evaluation metric that grades generated text based on semantic similarity (meaning), rather than relying only on exact word overlap.

It uses contextual embeddings from pretrained language models such as BERT to compare the meaning of words in the candidate text and reference text.

### Evaluation Process

1. **Input:** Provide the candidate text and reference text.
2. **Embedding:** Use a pretrained language model to convert each token into a contextual embedding.
3. **Similarity Calculation:** Calculate cosine similarity between token embeddings.
4. **Greedy Matching:** Match each token with its most similar token in the other text.
5. **Calculate:** Compute Precision, Recall, and F1-Score.

### Cosine Similarity Formula

$$
S_{ij} = \frac{x_i^T y_j}{\|x_i\|\|y_j\|}
$$

Where:
- $$\(x_i\)$$ = Embedding of token \(i\) in the candidate text.
- $$\(y_j\)$$ = Embedding of token \(j\) in the reference text.
- $$\(S_{ij}\)$$ = Cosine similarity between the two token embeddings.

### BERTScore Formulas

**Precision:**

$$
P = \frac{1}{|C|}\sum_{x_i \in C}\max_{y_j \in R}S_{ij}
$$

**Recall:**

$$
R = \frac{1}{|R|}\sum_{y_j \in R}\max_{x_i \in C}S_{ij}
$$

**F1-Score:**

$$
F1 = \frac{2PR}{P+R}
$$

Where:
- \(C\) = Candidate tokens.
- \(R\) = Reference tokens.

**Advantages:**
- Evaluates semantic similarity instead of only exact word matching.
- Can recognize some paraphrases and different expressions with similar meanings.
- Uses contextual information from pretrained language models.

**Limitations:**
- Requires more computational resources than simple overlap metrics.
- Results depend on the pretrained model and configuration.
- Semantic similarity does not guarantee factual correctness.
- May assign high similarity to statements that have similar wording but different meanings.

## 8. Word Error Rate (WER)

### Definition
Word Error Rate (WER) is an evaluation metric commonly used in Automatic Speech Recognition (ASR) to measure how many word-level errors exist in a generated transcription compared with the reference transcription.

It measures the number of words that must be changed, inserted, or deleted to transform the predicted transcription into the reference transcription.

### Three Types of Errors

1. **Substitution (S):** A word is replaced with an incorrect word.
   - Reference: "I like AI."
   - Candidate: "I love AI."
   - Error: "like" → "love".

2. **Deletion (D):** A word in the reference is missing from the candidate.
   - Reference: "I like AI."
   - Candidate: "I AI."
   - Error: "like" is missing.

3. **Insertion (I):** An extra word appears in the candidate.
   - Reference: "I like AI."
   - Candidate: "I really like AI."
   - Error: "really" is inserted.

### Formula

$$
WER = \frac{S+D+I}{N}
$$

Where:
- \(S\) = Number of substitutions.
- \(D\) = Number of deletions.
- \(I\) = Number of insertions.
- \(N\) = Total number of words in the reference transcription.

### Evaluation Process

1. Compare the reference transcription with the predicted transcription.
2. Align the words using minimum edit distance.
3. Count substitutions, deletions, and insertions.
4. Divide the total errors by the number of reference words.

**Advantages:**
- Easy to understand and interpret.
- Widely used in speech recognition evaluation.
- Identifies different types of transcription errors.

**Limitations:**
- Does not measure semantic similarity.
- A small word difference can produce an error even when the meaning is unchanged.
- Depends on consistent text normalization and tokenization.
- WER can exceed 100% when the number of insertions is large.

**Important:** A lower WER indicates better transcription performance. A WER of 0 means there are no word-level errors.

## 9. Character Error Rate (CER)

### Definition
Character Error Rate (CER) is similar to WER, but instead of comparing words, it measures errors at the character level.

It is commonly used in OCR (Optical Character Recognition), handwriting recognition, and speech recognition, especially for languages where character-level evaluation is useful.

### Three Types of Errors

- Substitution (S): An incorrect character replaces the correct character.
- Deletion (D): A character from the reference is missing.
- Insertion (I): An extra character appears in the prediction.

### Formula

$$
CER = \frac{S+D+I}{N}
$$

Where:
- \(S\) = Number of character substitutions.
- \(D\) = Number of character deletions.
- \(I\) = Number of character insertions.
- \(N\) = Total number of characters in the reference text.

### Example

- Reference: "CAT"
- Candidate: "CUT"

Only one character is incorrect (A → U).

$$
CER = \frac{1}{3} = 0.3333
$$

Therefore, the CER is approximately 33.33%.

### Evaluation Process

1. Compare the reference text with the candidate text.
2. Align the characters using minimum edit distance.
3. Count substitutions, deletions, and insertions.
4. Divide the total character errors by the number of reference characters.

**Advantages:**
- Useful for character-level text evaluation.
- Can identify small spelling and recognition errors.
- Particularly useful for OCR and languages without clear word boundaries.

**Limitations:**
- Does not measure semantic meaning.
- A minor spelling difference can increase the error rate.
- Results depend on text normalization, such as spaces, punctuation, and Unicode handling.

**Important:** A lower CER indicates better performance. A CER of 0 means the predicted text matches the reference at the character level.

## 10. Comparative Evaluation of LLM Metrics

Different evaluation metrics measure different aspects of model performance. No single metric can fully evaluate every type of LLM output.

### Comparison Table

| Metric | What It Measures | Common Applications | Better Result |
|---|---|---|---|
| Exact Match (EM) | Exact answer correctness | QA, MCQ, mathematics | Higher |
| Accuracy | Overall classification correctness | Classification | Higher |
| Precision | Correctness of positive predictions | Classification | Higher |
| Recall | Coverage of actual positive cases | Classification | Higher |
| F1-Score | Balance between Precision and Recall | Classification | Higher |
| BLEU | N-gram precision overlap | Machine translation | Higher |
| ROUGE | Reference information overlap | Text summarization | Higher |
| METEOR | Word matching and word order | Machine translation | Higher |
| BERTScore | Semantic similarity | Text generation, summarization | Higher |
| WER | Word-level transcription errors | Speech recognition | Lower |
| CER | Character-level transcription errors | OCR, speech recognition | Lower |

### Key Differences

**1. Exact Matching Metrics**
- EM checks whether the entire answer matches the reference.
- Accuracy measures the proportion of correct classification predictions.
- Precision, Recall, and F1-Score provide more detailed classification evaluation.

**2. Text Overlap Metrics**
- BLEU focuses mainly on n-gram precision.
- ROUGE focuses mainly on reference content coverage.
- METEOR considers word matching, stemming, synonyms, and word order.

**3. Semantic Similarity Metrics**
- BERTScore uses contextual embeddings to compare meaning.
- It can recognize some semantically similar expressions even when the words are different.

**4. Error Rate Metrics**
- WER measures word-level errors.
- CER measures character-level errors.
- Both are based on edit distance and are commonly used for transcription evaluation.

### Which Metric Should We Use?

| Task | Recommended Metrics |
|---|---|
| Multiple-choice questions | Exact Match, Accuracy |
| Mathematical question-answering | Exact Match |
| Classification | Accuracy, Precision, Recall, F1 |
| Machine translation | BLEU, METEOR, BERTScore |
| Text summarization | ROUGE, BERTScore |
| Open-ended question-answering | Exact Match (when appropriate), BERTScore, human evaluation |
| Speech recognition | WER, CER |
| OCR | CER, WER |

### Final Understanding

- **EM:** Is the answer exactly correct?
- **Accuracy:** How many predictions are correct overall?
- **Precision:** How many predicted positives are correct?
- **Recall:** How many actual positives are found?
- **F1-Score:** How well are Precision and Recall balanced?
- **BLEU:** How much n-gram overlap exists between generated and reference text?
- **ROUGE:** How much reference information is captured?
- **METEOR:** How well do the words and their order match?
- **BERTScore:** How similar are the meanings of the two texts?
- **WER:** How many word-level errors exist?
- **CER:** How many character-level errors exist?

**Important conclusion:** Evaluation metrics should be selected according to the task. A high score does not always mean that an LLM produces a factually correct, useful, or reliable answer. For open-ended LLM evaluation, automatic metrics should ideally be combined with human evaluation and factuality checks.
